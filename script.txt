@bullets What is AWS? | Amazon Web Services — a cloud provider | Rent compute, storage, databases on demand | Scale up for spikes, down when quiet | Pay only for what you use
Let's start with the big picture. Amazon Web Services, or A.W.S., is a cloud provider. Instead of buying physical servers, waiting for them to arrive, and setting them up yourself, you rent computing power, storage, and databases on demand, in minutes. Need more capacity for a traffic spike? Scale up. Quiet night? Scale down, and stop paying for what you don't use. That flexibility changed how software is built, which is why so many startups and global companies run on {AWS|Amazon Web Services} today.

@big A big box of building blocks | Each service does one job well — the skill is combining them
Now, {AWS|Amazon Web Services} has a lot of services, and seeing them all at once can feel overwhelming. Don't worry about that. I think of {AWS|Amazon Web Services} like a big box of building blocks. Each service does one job well, and the real skill is knowing which blocks to combine for the system you need. We'll pick them up one at a time, and by the end of this course, you'll know how they fit together.
